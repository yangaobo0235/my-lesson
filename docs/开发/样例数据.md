## 2. 合成业务与设备

体验企业、账号显示名、工单标题及资产编号均带“合成”或`SYNTHETIC`标记。电脑和打印机使用合成型号，序列号留空；设备地点明确为本地实验环境，不能借用真实厂商型号宣称兼容认证。

四类初始现象分别为登录黑屏、共享打印失败、休眠后Wi-Fi断连及Edge翻译异常。工单记录“未进行修复”，先由技术人员接单并核对环境。支持资格按服务项目开通，与设备登记独立；软件及网络问题也允许不绑定设备。

知识和工单经正式管理/客户接口创建，不直接向表中插入伪造审计。原上传键、索引键、建单键及返回身份先落本机记录；超时按原键查询，不能换键创建重复业务。脚本重入先查询已创建资源，唯一业务原件保存在OSS，不依赖可删除的`.local`副本。

## 3. 可复现的模拟反馈

领域题集另见[领域评测](领域评测.md)：20个原因/环境族、60个实例，隐藏原因不进入Agent，模拟器只接受精确的已审核检查身份和指令。实例预先区分应解决、必须交接及无法安全确认，只有收到模拟用户复测反馈才记模拟恢复。

领域评测使用独立服务项目及知识，不能把新公开资料混入冻结批次。公开资料适合验证真实长文、定位、版本与权限；合成规程适合验证可重复决策与反馈。两者分别报告，不把公开手册数量算成实机故障数量，也不把成功索引算成排障成功。

## 4. 导入与核验

通过知识管理页面建立系列，填写署名、固定来源、许可及转换说明，上传纯文本Markdown，限定受众和适用规则。索引经RocketMQ受理，worker完成Embedding及ES/Qdrant两路核验后才发布。原件被拒绝时修正输入材料，不能放宽HTML或远程资源校验。

发布后分别验证技术人员有权读取、客户不能读取仅支持人员资料、不匹配系统/软件环境不能取用，以及精确原件摘要一致。资料更新建立新修订；发现风险走撤回或撤权，不能原地替换已发布正文。许可或技术适用性存疑的材料保持草稿。

导入批次、设备和工单身份、原件清单、验证输出放根`.local/<任务>/`，本机体验与验收说明放`docs/开发计划/`，均不提交凭据和真实客户数据。
