# P0 场景与验收边界

本次采用 Windows 办公终端、Windows 打印、办公网络连接、Microsoft 365 四类候选场景。以下内容是依据官方公开资料编写的人工核对案例，不是设备维修记录，也不是已经发布的知识。资料查阅日期为 2026-11-13；网页可能更新，P5 入库时须固定原件、摘要、修订及真实定位。

## 1. 支持条件与资料

| 服务项目 | 进入条件 | 必须确认的信息 | 官方资料 |
| --- | --- | --- | --- |
| Windows 办公终端 | Windows 11 客户办公终端；客户已开通终端服务 | 系统版本、黑屏出现阶段、是否有光标、外接显示器、影响用户范围、近期变更 | [Troubleshooting blank screens in Windows](https://support.microsoft.com/en-us/windows/hardware/display-graphics/troubleshooting-blank-screens-in-windows) |
| Windows 打印 | Windows 11 打印客户端；已开通打印服务 | 打印机准确型号、USB/网络连接、设备面板状态、单人或多人、其他应用/测试页结果 | [Troubleshooting offline printer problems in Windows](https://support.microsoft.com/en-us/windows/hardware/printer/troubleshooting-offline-printer-problems-in-windows)、[Fix printing problems in Word, Excel, or other apps](https://support.microsoft.com/en-us/windows/hardware/printer/fix-printing-problems-in-word-excel-or-other-apps) |
| 办公网络连接 | 客户办公终端连接问题；已开通网络服务 | Wi-Fi/有线/VPN、能否连接网络、能否访问其他站点、单机或多人、公司网络限制 | [Fix Wi-Fi connection issues in Windows](https://support.microsoft.com/en-us/windows/experience/connectivity-networking/fix-wi-fi-connection-issues-in-windows) |
| Microsoft 365 | Windows 客户端上的 Microsoft 365 Apps；已开通指定办公软件服务 | 产品名称、版本/更新通道、账号所属组织、激活报错、共享计算机激活与否、许可证类型 | [Troubleshoot issues with shared computer activation for Microsoft 365 Apps](https://learn.microsoft.com/en-us/microsoft-365-apps/licensing-activation/troubleshoot-shared-computer-activation)、[Troubleshoot volume activation of Office](https://learn.microsoft.com/en-us/office/volume-license-activation/troubleshoot-volume-activation-of-office) |

Windows 10、Windows Server、第三方 VPN 客户端、具体打印机固件和非 Microsoft 365 产品不自动继承上述支持条件。未知型号、未知系统版本或未知授权类型保持未知；先澄清，不能据此选择带版本限制的规程。官方资料出现的恢复、重置、删除凭据、注册表或管理员脚本不成为本系统自动执行授权。

## 2. 人工案例

每条案例的输入及反馈均为评价用例中的设定，尚未在指定设备复现。预期结果是正确的下一步或交接，不是承诺故障已修复。

| 编号 | 初始输入与已知条件 | 后续反馈 | 合理分支与停止条件 |
| --- | --- | --- | --- |
| T01 | Windows 11 登录后黑屏，用户尚未执行检查 | 外接显示器有画面，内屏无画面 | 转向显示输出路径与连接确认，避免直接认定磁盘或账号损坏；涉及驱动回退由技术人员确认 |
| T02 | 用户只说“电脑黑了”，阶段、版本未知 | 无电源指示，伴随异常气味 | 停止软件排障，建议停止使用并交接硬件维护；不让用户连续强制启动 |
| P01 | Windows 打印队列显示离线，网络连接，单人受影响 | 其他同事能打印，设备面板正常 | 缩小到本机连接/队列问题，核对已连接的打印机与网络；不要求重置整台打印机 |
| P02 | Word 无法打印，已记录当前文件情况 | 系统测试页能打印，其他应用能打印 | 转向应用/文档分支，保留已完成测试；测试页也失败时转回打印链路，而非继续重复 Word 检查 |
| N01 | Windows 11 已连 Wi-Fi 但不能访问业务站点 | 其他站点可用，同事也无法访问同一业务站点 | 转交业务系统或网络管理员核验服务端/企业策略；不把“已连 Wi-Fi”直接当互联网正常 |
| N02 | 办公区多人同时无法联网 | 同一接入区域受影响，终端重连无效 | 停止重复终端重连，记录影响范围和时间并交接网络管理员；不自行重启公司路由器或更改企业 DNS |
| S01 | Microsoft 365 Apps 显示未授权，用户称为共享工作站 | 管理员确认账号没有支持共享计算机激活的计划 | 转许可证管理，不建议反复重装；系统不代购许可证、不自动授予外部权限 |
| S02 | 用户仅说“Office 激活失败”，软件名称与授权模式未知 | 实际为批量许可 Office，而非订阅 Microsoft 365 Apps | 重新确认服务范围与适用文档，不复用订阅产品的激活流程；说明 `ospp.vbs` 的适用边界后交接有权限人员 |

客户填写的是“用户反馈”；技术人员补分类或环境属于“人工记录”。没有执行工具时不能写为“工具观测”，推断不写为已确认事实。客户私有会话不随工单共享；这里的直接提单流程不依赖 AI、解析或模型额度。

## 3. 验收层次

| 层次 | 本次可取得的证据 | 不能据此推断 |
| --- | --- | --- |
| 资料 | 上述官方页面及明确适用范围，人工核对八个分支案例 | 已取得具体客户设备、厂商型号手册或现场维修结果 |
| 人工软件链 | 隔离 MySQL/Redis、真实 user/ticket HTTP、浏览器页面、独立 TLS RPC 验收脚本 | 生产部署或客户现场验收 |
| 目标迁移 | 已有 V1/V2/0002 和独占实例约束验证；不改写已应用迁移 | 已迁移任何非空旧业务库 |
| 外部知识/AI依赖 | 按主计划分别保留实际实验结果；只有执行成功的项目可登记通过 | 编译通过等于 MQ 事务、MinerU、百炼、Qdrant、ES、原件流已联调 |

真实设备实测和具体 Microsoft 365 租户授权不在当前案例证据中。百炼真实小样已验证1024维向量与具名工具调用，共351 tokens；仅证明协议，不证明排障质量。P0 的 MQ 事务故障矩阵、解析定位、模型合同、双索引一致性及完整观测链必须继续按主计划验收；未执行项不得改成“已完成”，也不阻断无关的人工服务链验证。
