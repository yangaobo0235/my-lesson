# P7–P8本地交付与验收

本记录把用户本次范围固定为“本地完整开发与运行”。P7工作台和管理处置已补齐，P8使用现有隔离验收脚本与固定证据完成可重复的行为核对；镜像、生产部署、联合备份和独立环境恢复属于后续部署任务，不计入本次交付。

## 1. P7实现

知识管理员现在可以从前端“共享反馈”入口分页查看客户明确共享的无帮助反馈，按待处理、已解决和已驳回筛选。列表只返回处置元数据；点击“核验并展开”时，AI服务重新核对客户会话未删除、共享仍有效、原运行成功，并通过原客户身份复核全部实际来源。任何来源撤权都会阻止展开。

处置动作使用反馈行版本和数据库行锁，解决与驳回都要求人工说明。客户在并发撤销共享、管理员重复处理或版本过期时收到冲突，不能覆盖新的状态。技术人员会话的反馈仍为RECORDED，不进入管理员队列，也没有共享开关。反馈不会自动生成知识修订，知识复用继续经过人工脱敏、来源复核和正式发布。

入口已同步到 AI HTTP、Gateway 白名单、Vue 路由、知识管理员导航和运行时协议解码。组合角色只获得明确角色对应的入口，后端仍逐次核验角色、会话、客户范围及来源。
