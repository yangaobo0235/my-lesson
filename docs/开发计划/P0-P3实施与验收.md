## 2. 可重复验证

正式入口见 `.github/workflows/verify.yml`。Java 使用 JDK 21，Python、Node、npm 及组件版本见[版本约定](../开发/版本约定.md)。以下命令从仓库根执行；数据库变量只通过环境提供，不写入命令行或提交的配置。

```text
mvn -B -ntp clean verify
python .github/scripts/check_structure.py
python .github/scripts/check_java_artifacts.py

cd desk-ai
uv sync --locked
uv run --locked ruff check --config pyproject.toml . ../.github/scripts
uv run --locked ruff format --check --config pyproject.toml . ../.github/scripts
uv run --locked pytest
uv run --locked python ../.github/scripts/build_ai.py --output ../.local/ci/wheel
uv run --locked python ../.github/scripts/verify_database.py --work-dir ../.local/ci/database
uv run --locked python ../.github/scripts/verify_application.py --work-dir ../.local/ci/application

cd ../desk-web
npm ci
npm run typecheck
npm run lint
npm run format:check
npm run test
npm run build
```

`verify_application.py` 要求 `DESK_VERIFY_ISOLATED=true`、回环专用 MySQL 地址和空业务表；使用 `DESK_VERIFY_HOST/PORT/USERNAME/PASSWORD` 及 `DESK_VERIFY_REDIS_PORT`，生成本次证书，启动并关闭自有 user/ticket/Gateway 进程。不能对共享或业务库运行。HTTP 经真实 Gateway 和静态服务发现，Feign 仍经过负载均衡适配；不冒充 Nacos 验收。
