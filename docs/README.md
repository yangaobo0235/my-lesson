开始开发先读开发规范，再读所属端规范、设计、入口及消费者。分页由 Java 后端规范统一，业务动作由系统设计定义，字段和约束由数据库设计定义，跨端协议及错误编号/边界映射由接口约定定义；公共能力和应用装配归属由项目结构定义，其他文档通过链接引用，不另建不同版本。实现进度与有效验证随具体改造任务交付，阅读入口见根README。

本体系采用职责清楚、完整用例、普通模型、显式边界和可重复验证的写法，针对本项目保留 Java/Python 双后端和微服务运行特征。正式文档独立可读，不要求访问参考仓库、聊天记录或临时调研。
